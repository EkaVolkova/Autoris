# Учебный проект по авторизации

Этот учебный проект предназначен для демонстрации базовых принципов авторизации пользователей в веб-приложении с использованием ASP.NET Core и Entity Framework Core. В проекте реализован контроллер, который управляет пользователями и ролями, предоставляет возможность аутентификации и получения информации о пользователях.

## Описание проекта

Проект позволяет выполнять следующие действия:
- Добавление ролей
- Добавление пользователей
- Аутентификация пользователей
- Получение информации о пользователях

## Модели данных

### Role

Класс Role представляет сущность роли в системе. Каждая роль имеет уникальный идентификатор и название. Роли могут быть связаны с несколькими пользователями, что позволяет организовывать доступ и разрешения в приложении.

### User

Класс User описывает сущность пользователя. Каждый пользователь имеет уникальный идентификатор, логин, пароль, имя, фамилию и адрес электронной почты. Связь с ролью пользователя осуществляется через RoleId, что позволяет определять, к какой роли принадлежит данный пользователь.

## Установка и запуск

Для работы проекта вам потребуется:

- .NET SDK (версия 5 или выше)
- SQL Express или другая совместимая база данных

### Шаги по установке

1. Клонируйте репозиторий: https://https://github.com/EkaVolkova/Autoris.git
2. Настройте строку подключения к базе данных в appsettings.json.
3. Запустите проект.

## Использование

### Методы контроллера

#### Добавление роли
- **HTTP Метод**: POST
- **Маршрут**: /Roles
- **Описание**: Позволяет добавить новую роль в систему.

#### Добавление пользователя
- **HTTP Метод**: POST
- **Маршрут**: /user
- **Описание**: Позволяет добавить нового пользователя в систему.

#### Аутентификация
- **HTTP Метод**: GET
- **Маршрут**: /authenticate
- **Описание**: Позволяет пользователю аутентифицироваться по логину и паролю.

#### Получение пользователя по логину
- **HTTP Метод**: GET
- **Маршрут**: /user
- **Описание**: Позволяет получить информацию о пользователе по его логину. Доступно только для администраторов.

#### Методы, недоступные без авторизации
- **Метод**: Получение информации о пользователе по логину (GET /user)
  - **Описание**: Этот метод доступен только для авторизованных пользователей. Необходимо пройти процедуру аутентификации.

## Примечания
